# attractor_in_eddy
This repository contains codes that compute the theoretically predicted characteristics of a circular attractor (assumed, therefore shown to exist) for inertial particles--modeled by the MRG equation with and without the nontrivial Basset-Boussinesq History (BBH) force--in a model for an ocean eddy. 
(doi: https://doi.org/10.1063/5.0336069)
